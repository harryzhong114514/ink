# Ink Tide

白天建造、夜晚守城的水墨风网页游戏。核心玩法：**怪潮会学习你的打法并进化**，比如你用火烧，下一夜的怪就长出防火的甲。

## 怎么打开游戏

浏览器直接打开 `index.html` 可能加载不了脚本，用下面任一方法：

- 在这个文件夹里运行 `python -m http.server 8765`，然后浏览器打开 http://localhost:8765
- 或者用 VS Code 装 Live Server 插件，右键 `index.html` 选 "Open with Live Server"

操作：WASD 移动，按住鼠标攻击，空格放技能，数字键 1-6 选建筑后点地图放置，右键拆除，回车提前入夜，M 静音。

## 分工（第一轮 5 小时）

每人只改自己的文件，这样合并时不会冲突。**不要改 `js/` 文件夹里的东西**，那是程序部分。

### 组员 A：英文文案，`data/text.js`

游戏里所有文字都在这个文件里，全是英文。

1. 用 GPT 润色：怪物、建筑、进化、遗物的名字和介绍，进化报告里的句子，`teaser`（每晚结束时的预告句）。
2. 风格：短、有画面感、有点神秘。比如进化的 `why` 要让玩家觉得"它们真的在学我"。
3. 只改引号里面的英文。不要动引号外面的名字、括号、逗号。
4. `{from}`、`{to}`、`{name}`、`{n}` 这种是游戏自动填的，要保留。
5. 句子别太长，界面放不下。改完打开游戏看一眼有没有超出边框。

### 组员 C：数值和试玩，`data/balance.js`

1. 自己从头玩 3 局以上，再找 3 到 5 个没玩过的同学玩前 10 分钟（前三夜）。
2. 每次试玩记录：活到第几夜、哪里卡住、哪里看不懂、哪里无聊、哪里最爽。记到 `playtest.md`（新建这个文件）。
3. 根据记录调 `data/balance.js` 里的数字。文件开头有说明，每个数字旁边有中文注释。**只改冒号右边的数字。**
4. 一次只改一两个数，改完重新玩一遍看效果，并在 `playtest.md` 里写下改了什么、为什么。
5. 目标：前三夜新手能活下来但会紧张；第四到第六夜开始吃力；第七夜 Boss 是最难的一战。

自动测试（可选）：网址后面加 `?test`（http://localhost:8765/?test），按 F12 打开控制台，输入 `tune(null, 5)` 回车，电脑会自动玩 5 局并显示每局结果。

## 怎么提交

最简单的方法，不用装任何东西：

1. 在 GitHub 网页上打开你负责的文件，点右上角的铅笔图标编辑。
2. 改完点 "Commit changes"，写一句改了什么，直接提交到 `main`。
3. 改之前先刷新网页，确保看到的是最新版本。

会用 git 的话也可以 clone 下来改，提交前先 `git pull`。

5 小时后全组一起试玩最新版，合并问题、定下一轮任务。
